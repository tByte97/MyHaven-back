# Архітектура та технічний дизайн бекенду MyHaven

**Версія:** 1.1 | **Оновлено:** 15 травня 2026 р.

## Обсяг проекту
MyHaven — це система управління особистими фінансами, що включає парсинг банківських виписок, категоризацію транзакцій та фінансову аналітику через веб-інтерфейс та Telegram.

## Архітектурні патерни

### 1. Патерн сервісного шару (Service Layer)
Бізнес-логіка зосереджена в модулях `services.py`. Представлення (Views) обмежені обробкою запитів/відповідей та делегуванням операцій сервісам.

### 2. Патерн репозиторію (Repository)
Логіка доступу до даних централізована в `repositories.py`. Це забезпечує послідовний інтерфейс для ORM-запитів та фільтрації.

### 3. Патерн стратегії (Strategy)
Парсинг банківських виписок використовує патерн Стратегія. Кожен формат банку обробляється специфічною імплементацією парсера, що відповідає спільному інтерфейсу.

### 4. Принципи SOLID
Проект дотримується принципів дизайну SOLID для забезпечення підтримуваності та масштабованості.

## Структура додатків

| Додаток | Відповідальність | Огляд логіки |
|---------|------------------|--------------|
| **core** | Конфігурація | Налаштування, маршрутизація та middleware. |
| **users** | Автентифікація та профілі | JWT, 2FA, налаштування та експорт даних. |
| **accounts** | Сутності | Управління банками та рахунками. |
| **transactions** | Основні операції | Парсинг, категоризація та розрахунок KPI. |
| **budgets** | Ліміти | Щомісячне управління бюджетами. |
| **telegram_api** | Інтеграція бота | Спеціалізовані API-ендпоінти для взаємодії з Telegram. |

## Моделі даних
- **CustomUser**: Ідентифікація користувача з профілем та метаданими Telegram.
- **Bank та Account**: Сутності для зберігання фінансових даних.
- **Category**: Системні та визначені користувачем класифікації транзакцій.
- **Transaction**: Основна фінансова одиниця, пов'язана з рахунками та категоріями.
- **Budget**: Щомісячні ліміти витрат на основі категорій.

## Технічний стек
- **Фреймворк**: Django 5.2.7, Django REST Framework 3.16.1.
- **База даних**: PostgreSQL.
- **Автентифікація**: JWT (djangorestframework-simplejwt).
- **Документація API**: OpenAPI 3.0 (drf-spectacular).
- **Парсинг**: pdfplumber, openpyxl, pandas.
- **Безпека**: pyotp, cryptography.
