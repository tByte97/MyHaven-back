# Посібник з розробки бекенду MyHaven

**Версія:** 1.1 | **Оновлено:** 15 травня 2026 р.

## Встановлення

### Передумови
- Python 3.10 або вище.
- PostgreSQL.
- Інструмент віртуального середовища.

### Процес налаштування
1. Перейдіть до директорії `backend`.
2. Ініціалізуйте та активуйте віртуальне середовище.
3. Встановіть вимоги: `pip install -r requirements.txt`.
4. Встановіть інструменти розробки: `pip install black ruff pytest pytest-django pytest-cov`.

### Конфігурація бази даних
1. Налаштуйте файл `.env`.
2. Застосуйте міграції: `python manage.py migrate`.
3. Створіть адміністратора: `python manage.py createsuperuser`.

### Запуск
Запустіть сервер розробки: `python manage.py runserver`.
- Сервер: [http://localhost:8000/](http://localhost:8000/)
- Документація API: [http://localhost:8000/api/docs/](http://localhost:8000/api/docs/)

## Робочий процес розробки

### Розробка через тестування (TDD)
1. Напишіть тест, що не проходить, у `tests.py`.
2. Реалізуйте мінімальний код для проходження тесту.
3. Рефакторіть імплементацію відповідно до стандартів якості.

### Команди тестування
- Виконати всі тести: `python manage.py test`.
- Виконати тести конкретного додатка: `python manage.py test <app_name>.tests`.
Поточний набір складається з 12 тестів.

### Перевірка перед комітом
Запустіть скрипт перевірки перед комітом змін:
- Windows: `.\run_checks.ps1`
- Unix: `./run_checks.sh`

## Стандарти кодування
- **Форматування**: Black formatter.
- **Лінтинг**: Ruff linter.
- **Підказки типів**: Обов'язкові для методів сервісів та репозиторіїв.
- **Docstrings**: Обов'язкові для класів та публічних методів.
- **Найменування**: `snake_case` для змінних та функцій; `PascalCase` для класів.

## Рекомендації щодо впровадження
- **Моделі**: Визначаються в `models.py`.
- **Логіка**: Реалізується в `services.py`.
- **Запити**: Містяться в `repositories.py`.
- **Ендпоінти**: Керуються у `views.py` та `serializers.py`.

## Усунення несправностей

| Проблема | Дія |
|----------|-----|
| Підключення до бази даних | Перевірте налаштування `.env` та статус PostgreSQL. |
| Невдалі тести | Переконайтеся, що міграції застосовані, а середовище ізольоване. |
| Відсутні імпорти | Перевірте активацію віртуального середовища. |
